BantooziBot

BantooziBot is the web fetcher of Bantoozi, an invite-only feed reader. If you found it in your server logs, this page explains what it does.

What it fetches

Public RSS, Atom and JSON feeds, and the public articles they link to, only because a reader subscribed to that feed or bookmarked that article. It does not crawl sites, submit forms or sign in anywhere.

How it behaves

  • It honours robots.txt for the product token BantooziBot.
  • It makes at most 2 concurrent requests per site, starting at most one per second.
  • It backs off when a site answers 429 or 503 and respects Retry-After.
  • It fetches each feed on an adaptive schedule, less often when a feed rarely changes.

User agent

BantooziBot/1.0 (+https://your-domain.example/bot)

Contact

To block the bot, add a BantooziBot rule to your robots.txt, or write to us: support@your-domain.example
